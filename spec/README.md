# spec/

The single source of truth for the public API, SDKs, MCP tools and the brain's
types. Change this first (see CONTRIBUTING.md).

- `openapi.yaml`: public REST API (`/v1`), OpenAPI 3.1.
- `schemas/`: JSON Schema 2020-12 for shared objects (Source, Watch, Trigger, Event, …).
- `mcp/tools.json`: the 8 MCP tools.
- `labels.json`: the detector's labels (person, vehicle, animal and 64 everyday
  objects, from COCO). The objects trigger's `label`, the Event `type`
  (`detection.<label>`) and the `brain.event` message type repeat it;
  `pnpm --filter @senseplane/spec labels` rewrites those enums (`pnpm codegen`
  runs it), and the brain, SDK (`LABELS`, `labelName`) and docs read it.
- `brain/valkey.json`: the Valkey keys, streams and messages between the API and the brain (ADR 0051).
- `auth/openapi.yaml`: the console sign-in routes (`/auth`).
- `media/`: the media contract between the API and any media plane (control API, tokens and golden vectors, signalling, callbacks, WHIP; ADR 0049). `media/vectors/tokens.json` is generated by `scripts/media-vectors.mjs` (`pnpm codegen`).

`pnpm --filter @senseplane/spec validate` checks everything compiles.
`pnpm codegen` regenerates the TypeScript SDK types and the brain's Python
models; CI fails if the committed output differs.
