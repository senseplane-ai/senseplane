## What was built
- **API:** API keys (hashed; looked up through an owner-defined function so
  RLS still applies), `POST/GET /v1/sources`, `GET/PATCH /v1/account`
  (retention), Ed25519 ingest tokens with a public JWKS, and the segment index
  and source status.
- **Media:** control API, token-checked signalling, one WebRTC server port per
  worker, and the `segments` egress (FFmpeg stream copy → ~6 s fMP4 → object
  storage). The image ships an LGPL FFmpeg built from source.
- **Console:** capture page (H.264, `contentHint = "detail"`, watching
  indicator, pause/stop, screen wake lock, audio only when `record_audio`) and
  a page to add a source and show its QR code.
- **Replay publisher** (`MEDIA_DEV_REPLAY=1`, dev and CI only) and an H.264 fixture.

## Known limits at the time
- The first segment appears ~11 s after the page goes live (FFmpeg probing +
