## Built
- Media: masked analysis feed (ADR 0019), audio replay for fixtures, LGPL
  FFmpeg build extended (rawvideo/f32le, fps/pad).
- Brain: motion with lighting handling, loudness, YOLOX-s, ByteTrack-style
  tracker with stationary check, zones, YAMNet, episode builder.
- API: events (`GET /v1/events`, `/v1/events/{id}`, feedback), signed webhooks
  with retries and a delivery log, `PATCH /v1/sources/{id}` (zones, masks,
  thresholds), sensor sources, `POST /v1/sources/{id}/readings`, history,
  `GET /v1/sources/{id}/now` (latest snapshot), event clips.
- Console: Zones and masks editor, Events feed and detail, Webhooks page.
- Fixtures: CC0 / CC BY clips from Wikimedia Commons (`fixtures/README.md`, `NOTICE`).

## Known limits
- **Start-up:** the first analysis frame arrives 2–4 s after a source starts
  when the publisher ignores keyframe requests (the replay publisher; real
  browsers answer within ~0.1 s). The doorstep fixture therefore holds its
  empty first frame for 6 s.
- YOLOX-s took ~200 ms per frame on 2 CPU threads (M1 Max); one brain worker
  handled a handful of busy cameras. Later tuning cut this (ADR 0054, 0055,
  [brain-tuning.md](brain-tuning.md)).
- The Zones editor was built but only smoke-tested without a live snapshot.
